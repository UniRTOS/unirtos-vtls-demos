# unirtos-vtls-demos

[中文](README.zh.md) | English

## Overview

unirtos-vtls-demos provides an overall demonstration of VTLS capabilities on UniRTOS.
This directory focuses on TLS secure communication examples, covering different socket/handshake combinations from blocking to non-blocking flows, so you can quickly understand VTLS integration patterns and select a suitable implementation route.
