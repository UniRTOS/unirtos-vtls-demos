# unirtos-vtls-demos

中文 | [English](README.md)

## 概述

unirtos-vtls-demos 用于展示 UniRTOS 下 VTLS 安全通信能力的整体方案。
该目录聚焦 TLS 通信示例，覆盖从阻塞到非阻塞的不同 socket 与握手组合流程，便于快速理解 VTLS 集成模式并选择合适实现路径。
